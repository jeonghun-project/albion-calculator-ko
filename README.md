# 알비온 제작 계산기 (한국어)

Nendys 계산기와 같은 기능을 게임 공개 데이터로 새로 구현한 한국어 버전입니다.
정제 · 제작 · 음식 · 물약 전부를 다루며, 파일 하나로 브라우저에서 바로 실행됩니다.

## 사용법

`index.html` 을 브라우저로 열면 끝입니다. 설치·서버 불필요.

* 시세는 열 때마다 [Albion Online Data Project](https://www.albion-online-data.com/) 에서 자동으로 받아옵니다.
* 설정(도시·집중·프리미엄 등)과 직접 입력한 가격은 브라우저에 저장됩니다.

## 기능

| | |
|---|---|
| 아이템 | 9,254종 — 한글 이름 검색 (정제품·무기·방어구·가방/망토·음식·물약·탈것·채집도구) |
| 반환율 | `B/(1+B)` · 도시 18% + 정제특화 40% / 제작특화 15% + 집중 59% + 일일 보너스 + 추가 보너스 |
| 일일 보너스 | 인게임 액티비티에서 오늘 뽑힌 것을 골라 실버(+10%)·골드(+20%)로 지정. 방어구는 `판금 갑옷`·`판금 투구`·`판금 신발` 처럼 부위 단위로 뽑히므로 부위별로 지정 |
| 경유 도시 | 후보마다 재료 구매·정제·제작·판매를 합쳐 들러야 하는 도시 수와 순서를 표시. `빠른 순회순` 정렬로 이동 적은 것부터 |
| 오늘 할 일 | 오늘 보너스 걸린 카테고리만 계산해 순위를 냄. 후보가 적어 조회도 가볍다 |
| 반환 제외 | 게임 데이터의 `maxreturnamount=0` 을 그대로 읽어 반환 대상이 아닌 재료를 구분 (아티팩트·토큰·연금 희귀 재료 등 1,294종) |
| 연쇄 제작 | 하위 재료를 "직접 제작"으로 바꾸면 원광까지 재귀 전개 (체인 정제 포함) |
| 분해 | 상위 연금 재료 분해(우수한→질 좋은→견고한), 물고기 손질 등 고정 변환 80종. 집중·자원 반환 없이 계산 |
| 인챈트 | 인챈트된 재료로 직접 제작 / 아래 단계 완제품 + 룬·영혼·유물(음식은 피시 소스, 물약은 연금 추출물)로 업그레이드 — 두 경로를 "레시피 선택"에서 비교. 업그레이드는 집중·사용료·자원 반환 없음 (4,518종) |
| 암시장 | 판매처로 선택 가능. 판매 주문/즉시 판매 모두 지원하며 장비류만 거래 |
| 원가 | 재료비 + 제작소 사용료(`아이템가치 × 0.1125 × 사용료/100`) |
| 수익 | 판매세 4%(프리미엄)/8% + 판매주문 등록비 2.5% 반영, 이익률·집중 1당 이익 |
| 시세 | 아시아/아메리카/유럽 서버, 도시별 판매주문·구매주문 가격, 데이터 나이 표시 |
| 빈 시세 보완 | 전 도시 시세를 한 번에 받아, 고른 도시에 값이 없으면 다른 도시 값으로, 어느 도시에도 현재 주문이 없는 재료는 7일 평균으로 채우고 출처를 표시. 완제품 판매가는 보완하지 않음 |
| 시세 추이 | 7일 거래량 가중 평균가와 일 거래량. 현재가가 평균에서 30% 이상 벗어나면 경고 |
| 최근 추세 | 최근 3일 체결가를 그 앞 7일과 견준 상승/하락률(거래량 가중). 마지막 체결이 3일 이상 지났으면 경과일 표시. `상승세순` 정렬 |
| 권장 수량 | 하루 거래량의 10~20%(기본 15%)만 걸도록 계산. 하루 물량 전부를 한 번에 걸면 시장을 눌러 악성 재고가 됩니다 |
| 28일 피크가 | 최근 4주 중 가장 높게 체결된 가격(거래 한두 건인 날 제외)과 그 가격에 판매 주문을 걸었을 때의 이익률 |
| 수동 입력 | 시세가 없거나 실제 거래가와 다를 때 재료·판매가를 직접 덮어쓰기 |
| 품질 | 탐색에서는 품질을 거르지 않고 시세가 있는 품질을 모두 따로 계산해 `품질` 열로 구분. 원가는 품질과 무관하고 판매가·거래량·피크가만 갈림 |
| 여정 한 바퀴 | 아이템 상세에서 재료 트리를 도시 단위로 다시 묶어 경로로 펼침 — ①정제 도시에서 원재료 구매·정제 ②제작 도시에서 남은 재료 구매·제작 ③판매처. 도시별 지출과 투입 자본·회수·순이익을 함께 표시 |
| 정제 순회 | 왕국 도시 5곳의 정제 특화(+40%)를 기준으로 도시마다 가장 이익 큰 정제품을 뽑고 한 바퀴 합계를 냄. 체인 깊이를 구매·1~3단계·최적 중에 고름 |
| 다음 단계 안내 | 정제 재료를 보고 있으면 상세 페이지에 그 재료를 쓰는 제작 특화 도시·소모 비중·그 도시에서 만들 수 있는 카테고리·그 도시에서의 실수령을 표로 표시. 이미 받은 전 도시 시세만 써서 추가 조회 없음 |
| 제작 수요지 | 정제 특화 도시는 생산지(싸다), 그 재료를 쓰는 제작 특화 도시는 수요지(비싸다). 어느 도시가 어떤 정제 재료를 얼마나 쓰는지 레시피에서 뽑아 표시 — 판자→림허스트 47%, 주괴→브릿지워치 46%, 가죽→림허스트 26%, 직물→포트 스털링 33%, 석괴는 제작 수요 없음 |
| 저장소 (IndexedDB) | 시세·추이를 브라우저에 저장해 다음에 열 때 네트워크 없이 씀. 값이 있는 행만 담아 전체 수집이 3.5MB. https 에서는 영구 저장을 요청하고 남은 용량도 표시 |
| 전체 수집 | 제작 가능 9,008종을 전 도시·전 품질로 훑어 저장 — 31요청 87초. 진행률 표시, 중단·재개, 6시간 내 받은 항목은 건너뜀. 한 번 채우면 전체 탐색이 시세 조회 0건 |
| 이상 호가 제외 | 7일 평균의 10배를 넘는 호가는 제외 (석회암 석괴 평균 62에 1억 짜리 주문이 실제로 존재). 안정성순은 평균에서 100% 넘게 벗어난 것도 제외 |
| 플립핑 | 만들지 않고 싸게 사서 비싸게 파는 것만 찾음. 저장된 시세로 계산해 요청 0건 0.08초. `급등순`(오늘 튄 것)과 `안정성순`(꾸준한 스프레드)으로 용도가 갈림. 같은 도시에서 사고팔 수 있는 건 따로 표시 |
| 수익 후보 탐색 | 목록 조건(카테고리·티어·인챈트·검색)에 걸리는 아이템을 한꺼번에 계산해 이익 나는 것만 추림. 이익·이익률·**집중당 이익**·거래량·**안정성**순 정렬 |
| 판매처 자동 선택 | 판매 도시를 `자동` 으로 두면 아이템마다 세후 실수령이 가장 큰 (도시 × 판매방식) 조합을 고름. 아시아 T5 무기 기준 60종 중 46종이 암시장 즉시판매로 갈림 |
| 걸러내기 | 최소 일 거래량 · 7일 평균比 최대 이탈 · 최소 개당 이익 임계값 |
| 장부 | 실제로 만든 것과 판 것을 적어 **실현 순이익**을 냄. 제작은 그 시점 개당 원가를 스냅샷으로 박고, 판매는 적용된 세율을 함께 남김. 아이템 단위 선입선출로 제작분을 소진해 판 물량의 원가·재고 평가를 구분. 오늘치 요약, JSON 내보내기/가져오기 |
| 제작 원가 실입력 | 제작 기록 시 재료별 '실제로 산 수량 × 평균 단가' 를 입력. 산 총액 ÷ 나온 개수가 곧 실제 개당 원가라 반환율을 따로 안 따져도 실측이 된다. 제작소 사용료·소모 집중·적용 반환율도 함께 기록 |
| 손실 기록 | 운송 중 사망 등으로 잃은 물량. 선입선출로 재고에서 빠지고 그 원가가 실현 순이익에서 차감된다 |
| 집중 회계 | 제작마다 소모 집중을 기록해 집중 1당 실현 이익을 낸다 |

## 게임 패치 후 데이터 갱신

아이템·레시피가 바뀌면 이 폴더에서 아래 3줄만 실행하면 됩니다.

```bash
curl -sL https://raw.githubusercontent.com/ao-data/ao-bin-dumps/master/items.json -o items_raw.json
curl -sL https://raw.githubusercontent.com/ao-data/ao-bin-dumps/master/formatted/items.json -o items_formatted.json
python3 build_data.py && python3 build_app.py
```

* `build_data.py` — 게임 덤프에서 레시피·한글명·아이템가치를 뽑아 `albion_data.json` 생성
* `build_app.py` — `app_template.html` 에 데이터를 넣어 완성본 HTML 빌드
* `fetch_icons.py` — 아이콘을 `icons/` 로 미러링하는 스크립트. **지금은 쓰지 않는다** (핫링크로 충분).
  쓰려면 실행 후 `app_template.html` 의 `icon()` 이 `icons/{id}.png` 를 가리키게 바꾼다
* 반환율·세금 수치는 `app_template.html` 상단 `bonusSum()` / `salesTax()` 에 있습니다

## 배포

`main` 브랜치 루트를 GitHub Pages 가 그대로 서빙합니다. 푸시하면 1~2분 뒤 반영됩니다.

    https://jeonghun-project.github.io/albion-calculator-ko/

시세 API 는 `Access-Control-Allow-Origin: *` 라 브라우저에서 직접 호출합니다 —
서버나 프록시가 필요 없어 정적 호스팅(Pages, Netlify, S3) 어디서든 동작합니다.
외부 네트워크 요청을 막는 샌드박스 환경에서만 시세가 비어 보입니다.
